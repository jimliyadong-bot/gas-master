## 1. 系统组成

| 组件 | 目录 | 说明 |
|---|---|---|
| 后端（单体） | `RuoYi/`（8 模块 Maven） | RuoYi 4.8.3 + Spring Boot 4.1.2 + MyBatis + Shiro + Quartz，端口 **9090** |
| H5 前端 | `h5/` | Vue 3 + Vite 5 + Vant 4 + Pinia + Router，dev 端口 **5300** |
| 数据库 | MySQL 8.x | 库名 `ry`（可改），utf8mb4 |
| 定时任务 | sys_job | 开票提醒/库存预警扫描（每天 9:00）、订单超时关单（每 5 分钟） |

**已交付功能**（阶段 1-7）：
- 阶段1：组织/角色/部门、库表与字典
- 阶段2：基础资料（采购商/站点/枪/枪价/商户配置）
- 阶段3：采购与库存（采购批次/到货/付款/台账/提醒）
- 阶段4：H5 认证（公众号 OAuth + JWT、短信验证码绑手机号、员工账号绑定）
- 阶段5：H5 主动下单（扫码进站→试算→下单→支付→核销码/会员码）
- 阶段6：员工班次、在线核销、会员码代下单、司机确认/拒绝、强制交班及后台班次记录
- 阶段7：优惠券模板、定向发放、H5 券包/选券折后支付、关单退券、主动下单请求号幂等

### 3.1 关键业务参数（`gas_config`，后台"参数配置"可改）

| 键 | 默认 | 说明 |
|---|---|---|
| `order.waitPay.minutes` | 15 | 待支付订单超时关单 |
| `order.waitConfirm.minutes` | 10 | 代下单等待司机确认超时关单 |
| `order.amount.max` | 99999 | 单笔下单金额上限（元） |
| `token.refresh.seconds` / `token.ttl.seconds` | 30 / 60 | 动态码刷新窗口/有效期 |
| `sms.code.*` | — | 验证码：5 分钟有效、60 秒间隔、同号日限 10、同 IP 日限 30、错 5 次作废 |
| `wx.appid` | 空 | 公众号 AppID（真实模式必填） |
| `h5.jwt.expire.hours` | 168 | H5 登录有效期 |

**敏感配置只通过环境变量注入，不在后台页面回显或修改：**

| 环境变量 | 必填条件 | 说明 |
|---|---|---|
| `GAS_H5_JWT_SECRET` | 生产必填 | JWT 签名密钥，至少 32 字节强随机值；本地 mock 未配置时自动生成随机密钥 |
| `GAS_WX_SECRET` | 真实公众号模式必填 | 公众号 AppSecret |
| `GAS_H5_MOCK_MODE` | 仅本地开发 | `true` 开启 mock；生产 Profile 开启会拒绝启动 |

### 3.2 mock 开关（重要）

| 参数 | 用途 |
|---|---|
| `--gas.h5.mock-mode=true` | 启动参数/yml。开启后：微信 OAuth 免真实公众号（openid=`MOCK-<code>`）、JS-SDK 返回占位签名、支付走 Mock 网关（模拟收银台）、`/api/pay/notify` 仅此模式受理。**生产环境严禁配置** |

## 4. 构建与启动

### 4.1 后端

```powershell
cd RuoYi
mvn clean package                  # 含全部 JUnit（连库，需先完成 §3）
# 生产（PowerShell 示例；密钥请用安全随机生成器产生并妥善保管）：
$env:GAS_H5_JWT_SECRET = "<至少32字节的强随机密钥>"
$env:GAS_WX_SECRET = "<公众号AppSecret>"
java -jar ruoyi-admin\target\ruoyi-admin.jar --spring.profiles.active=prod
# 本地开发（免验证码 + mock 授权/支付；JWT 使用进程内随机密钥）：
java -jar ruoyi-admin\target\ruoyi-admin.jar --shiro.user.captchaEnabled=false --gas.h5.mock-mode=true
```

### 4.2 H5 前端

```powershell
cd h5
npm install
npm run dev          # http://localhost:5300，/api 代理到 9090
npm run build        # 产物 dist/，交 Nginx 托管
```

### 4.3 生产 Nginx 参考配置

```nginx
server {
    listen 80;
    server_name h5.example.com;

    root /opt/gas-h5/dist;           # npm run build 产物
    location / { try_files $uri $uri/ /index.html; }

    location /api/ {
        proxy_pass http://127.0.0.1:9090;
        # OAuth redirect_uri 按外部域名构造所必需：
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

后台管理端 Nginx 同理反代 9090（`/prod-api` 路径约定见 RuoYi 默认配置）。

## 5. 开业初始化（后台操作步骤）

后台地址 `http://<server>:9090`，admin/admin123（首次登录请改密）。

1. **系统管理 → 部门**：把根部门"采购方"改为实际公司名
2. **基础资料 → 采购商**：建采购商（通知手机号用于采购提醒）
3. **基础资料 → 站点**：建站点（自动建同名部门、生成二维码 `qr_token`）
4. **基础资料 → 加气枪**：给站点建枪（CNG/LNG）
5. **基础资料 → 枪价管理**：给每支枪设当前价（无价的枪 H5 下单页显示为禁用）
6. **商户配置**：给采购商配拉卡拉商户号（通道 LAKALA；**未配置则 H5 无法发起支付**）
7. **系统管理 → 用户**：建加气员/站点管理员账号，部门挂到站点部门下，角色分别选"加气员"/"站点管理员"
8. **采购与库存 → 采购批次**：录入批次 → 到货入库（**入库后站点池才存在，H5 才可下单**）→ 按需登记付款/开票
9. 打印站点二维码（`基础资料 → 站点 → 二维码`，内容为 `{h5.base.url}/station/{qr_token}`）

## 7. 常见问题（FAQ）

| 现象 | 原因/处理 |
|---|---|
| 前端 dev 起不来 `EACCES` | 端口在 Windows 排除段内，改 `vite.config.js` 端口后同步 `h5.base.url` |
| H5 提示"未登录"循环 | `h5.jwt.secret` 变更后旧 token 失效属预期，重新授权即可 |
| H5 业务异常返回 HTML 而非 JSON | 请求需带 `X-Requested-With: XMLHttpRequest`（前端 axios 已统一注入） |
| 下单提示"暂未开放销售" | 站点库存池未初始化——先在后台完成采购到货入库 |
| 发起支付提示"收款商户未配置" | 给站点所属采购商配置拉卡拉商户号（商户配置页） |
| 支付成功但订单仍待支付 | 真实模式下 `/api/pay/notify` 验签未接入前是关闭的（安全守卫），接入后恢复 |
| quartz 任务不跑 | 后台"监控 → 定时任务"确认状态正常；改库后需重启（cron 在 sys_job） |
| 冒烟后数据残留 | 各 smoke 脚本 finally 自带清理；手工测试数据按 `JUNIT`/`冒烟` 前缀清理 |
